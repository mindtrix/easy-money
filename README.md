# Бюджет

Личное приложение для учёта денег по двум периодам месяца — с 15-го (после зарплаты) и с 30-го (после аванса).
Работает в браузере телефона, ставится на главный экран как обычное приложение и открывается без интернета.

## Что умеет

- **Текучка.** Категории с лимитом на период, потраченным и остатком. Полоса зелёная, с 75% жёлтая, сверх лимита красная. Трата вносится тапом по карточке или голосом («продукты 500»).
- **Период.** Приход, кредиты и обязательные платежи, лимиты текучки и итог: «Остаётся» или «Перерасход». Отметка оплаты, частичная оплата, редактирование любого поля.
- **План следующего периода.** Вторая вкладка на экране «Период». Из него новый период создаётся сам.
- **Смена периода.** 15-го и 30-го (в коротком месяце — в последний день) прошлый период уходит в архив, неоплаченное переносится в новый красным блоком.
- **Архив.** Все закрытые периоды с тратами, платежами и долгами.
- **Копия данных.** Сохранение в файл и восстановление из файла (Настройки).

## Где данные

Только на телефоне, в хранилище браузера. Код на GitHub данных не содержит и никуда их не отправляет.
Исключение — голосовой ввод: фразу распознаёт Chrome через серверы Google.

Если очистить данные Chrome или удалить сайт в его настройках, данные пропадут. Поэтому раз в пару недель
делай **Настройки → Сохранить копию**. Файл `budget-ГГГГ-ММ-ДД.json` ляжет в «Загрузки».

## Где опубликовано

Адрес приложения: **https://mindtrix.github.io/easy-money/**

GitHub Pages публикует сайт из ветки `gh-pages`. Ветка `main` — основная копия кода, в обеих лежит одно и то же.
Репозиторий публичный: на бесплатном тарифе Pages работает только с публичными. Личных данных в коде нет,
они живут только на телефоне.

## Как поставить на телефон

1. Открой адрес в Chrome на телефоне.
2. Меню (три точки) → **Установить приложение** или **Добавить на главный экран**.
3. При первом голосовом вводе разреши доступ к микрофону.

## Как выпустить новую версию

1. Измени файлы.
2. **Обязательно** поменяй строку `VERSION` в начале `sw.js` (например, `budget-1.0.1`). Без этого телефон продолжит
   показывать старую версию из кэша.
3. Отправь изменения в обе ветки: `git push origin main main:gh-pages`. Сайт обновится через минуту-две.
4. При следующем запуске с интернетом приложение на телефоне обновится само и перезагрузится.

## Устройство

| Файл | Что внутри |
|---|---|
| `index.html` | оболочка страницы |
| `style.css` | внешний вид, светлая и тёмная тема |
| `logic.js` | расчёты без интерфейса: деньги, периоды, перенос долгов, разбор голосовой фразы |
| `app.js` | интерфейс, хранение, голос, копия данных |
| `sw.js` | офлайн-кэш |
| `manifest.webmanifest`, `icons/` | установка на главный экран |
| `fonts/` | шрифт Manrope (лицензия OFL в `fonts/OFL.txt`) |
| `tests/logic.test.js` | проверки логики: `node tests/logic.test.js` |

Суммы хранятся в копейках, даты периодов — строками `ГГГГ-ММ-ДД`.
